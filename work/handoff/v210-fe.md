- 새 스냅샷 판정 = `study.inputs.shape_rules` 존재(settings 아님). 키 없으면 새 UI 요소가 하나도 안 그려짐(옛 화면 동일).
- `DoeSettingsOut.shape_rules` 는 타입에 두지 않음: UI 가 안 쓰고, openapi(backend 소유)에 없으면 check:api 가 실패하기 때문. backend 가 openapi 에 넣으면 필요 시 추가.
- guard 기준값(jac_min 등)·rank_quality 임계는 스냅샷 shape_rules 에서만 읽음(툴팁). 스냅샷에 없으면 값만 표시.
- 순위는 서버 순서 그대로(재정렬·제외 없음). best_clean_mq 는 summary 키가 있으면 그 값(null=없음), 키가 없으면 mq 없는 최상위 행.
