# 비드 형상 변경용 ESL 방법론 선정

2026-11-18. 사용자 정정에 따라 이전 탄소성·설계안 탐색 벤치마크와 분리한다.

## 목적과 금지 범위

목적은 정해진 비드 형상 변경을 입력했을 때 실제 동해석 변위장을 잘 예측하는 방법론을 고르는 것이다.
형상을 최적화하거나 최선의 비드 깊이를 찾지 않는다. 소성 재료·소성 제약·개선율 목표를 사용하지 않는다.
테스트 형상은 결과를 보기 전에 config/shape_method_validation.json에 고정한다.

## 공통 물리 조건

800x450x0.8 mm 판, 960개 쉘, 1,025절점. E=210000 MPa, nu=0.3, rho=7.85e-9 tonne/mm3.
실제 입력 재료는 /MAT/ELAST (LAW1)이다. 높은 항복응력을 준 LAW2를 탄성 재료 대신 사용하지 않는다.
낙하는 600 mm에 해당하는 초기 하향속도 3.431035 m/s, 중력 9.81 m/s2.
강체 바닥 마찰 0.15. 판은 동해석에서 무구속이다.
충돌 직전부터 40 ms. 기하 대회전과 접촉은 포함하되 재료는 탄성이다.

자세를 명시적으로 구분한다. 기존 Rx=+3도, Ry=-4도는 수평에서 약 5도 기울인 코너 최초 접촉 대조 조건이다.
이를 대표 코너 낙하 자세로 취급하지 않는다. 본 선정용 조건은 판의 평면 대각선(코너-중심)이
세계 수직 방향에 놓이는 90도 세운 자세이며, 절점 1이 최저 코너다. 이 각도는 사용자가 수치로
지정한 값이 아니라 이번 검증에서 명시한 기하학적 코너 낙하 정의다. 두 조건의 데이터를 섞지 않는다.

정해석은 초기 판 좌표계의 선형 쉘이고 바닥 접촉은 없다. 공통 3-2-1 구속을 고정한다.
절점 1025=(800,450,0):123, 1001=(800,0,0):13, 25=(0,450,0):3.
구속 의존성 검사는 1=(0,0,0):123, 1001:23, 25:3의 별도 게이지로 수행한다.
이 구속을 실제 체결로 해석하지 않는다. 반력·하중 합력/모멘트와 게이지 변경 후 비강체장 차이를 기록한다.

## 방법 정의

비교 코드 수를 문헌 대안 수로 표현하지 않는다. 평형 보정은 진단/안정화이고 Taylor 응답은 대조군이다.
Khat는 쉘 회전을 자유 상태로 응축한 병진 강성이다. u_dyn은 동일 절점과 판 좌표계의 강체 제거 변위다.

| 코드 | 정확한 계산 | 지위 |
|---|---|---|
| frozen | f0(t)=Khat(p0)u0(t)를 고정하고 K(p)로 재풀이 | 기존 ESL 대조군 |
| balanced | 후보 좌표·질량으로 f0의 합력·모멘트를 관성완화한 뒤 재풀이 | 평형/구속 진단 |
| incremental | 기준 변형 형상의 Khat_i*Delta u0_i, 후보 형상 X(p)+u0(t_i)에서 증분 풀이 및 누적 | DiESL의 명시적인 동일 절점 형상 확장; 문헌 비드 예제 재현이라고 하지 않음 |
| incremental_balanced | 같은 증분 하중을 후보 변형 형상의 좌표와 후보 초기 절점 질량으로 평형화한 뒤 누적 | 증분 풀이의 구속 의존성 진단 |
| first_order_load | f0 + sum_j d(Khat*u_dyn)/dp_j * dp_j를 후보 K로 풀이 | F-ESL형 1차 하중; 중앙차분 동해석 미분 사용 |
| first_order_balanced | 위 1차 하중에 후보별 관성완화 적용 | 유한 형상 변경의 2차 평형 오차 영향 분리 |
| response_taylor | u0 + sum_j du_dyn/dp_j * dp_j | 직접 동해석 1차 응답 근사 대조군; ESL 정해석을 대신 검증한 것으로 표현하지 않음 |
| snapshot_esl | 기준 변형의 주성분으로 만든 부분공간에서 후보 정적 강성으로 변위 보정 | 추가 보정 낙하 0회인 실험적 ESL |
| reference_replay | 후보에서 강체 성분만 제거한 기준 동해석 변위 재사용 | 형상 변경이 없는 것으로 예측하는 대조군 |

### 축소 ESL

기준 동해석 스냅샷을 SVD해 변위 제곱합의 99.9%를 담는 기저를 사용한다.
후보 형상에서 미소 강체 모드를 제거하고 정규직교화한 기저를 `V`라고 한다. 후보 강체 성분을 제거한 기준 변위 `u_ref`에서 시작한다.

```text
(Vᵀ Khat(p) V) a = Vᵀ [f0_balanced − Khat(p) u_ref]
u_pred = u_ref + V a
```

`f0_balanced`는 후보 좌표와 질량에서 관성완화한 기준 ESL이다. 변위를 보정하는 방향을 기준 낙하에서 관측한 공간으로 제한한다. 회전 응축은 기존 쉘 모델을 사용한다. 미소 강체 모드를 제거한 공간에서 풀기 때문에 절점에 점구속을 부과하지 않는다. 모드 수, 축소 강성 조건수, 보정 후 남은 잔차를 기록한다.

F-ESL 원문 arXiv:2508.07222 Eq.(4)-(6)는 선형 동적 응답을 대상으로 한다.
여기서는 접촉/대회전이 있는 탄성 판에 그 1차 하중 정의를 시험한다. 이 확장을 이미 입증된 것으로 취급하지 않는다.
중앙차분 간격은 각 비드 +/-0.05 mm이다. 12개 보정 해석과 독립 검증 해석의 역할을 바꾸지 않는다.
비드 5의 +/-0.025 mm는 미분 간격 확인용이며 모델 학습에는 사용하지 않는다.

## 공정한 비교와 선정 기준

1. 모든 방법은 기준 동해석에서 정한 공통 시점과 동일한 절점 대응을 사용한다.
2. 기준 변위 왕복 재현, 독립 형상에서 변위장 상대 L2·피크 RMS 오차·개선/악화 방향을 확인한다.
3. +/-0.1 mm 이내의 독립 테스트 영역과 0.5 mm 확장 테스트를 분리한다.
4. 사전 기준: 변위장 상대 L2 <=15%, 피크 RMS 상대오차 <=10%, 기준 왕복 <=1e-4,
   게이지 변경 후 비강체장 차이 <=1e-4, 변화 방향 일치 >=80%.
5. 수치 오류, 시간 샘플링, 근사 오차를 구분한다. 기준/혼합 변경안은 3,840개 쉘에서도 동해석해 추세를 대조한다.
6. 기준 1회로 가능한 방법과 12회 추가 동해석 미분이 필요한 방법의 초기 비용을 별도 보고한다.
7. 성공 기준을 통과한 범위에서만 방법을 선정한다. 통과하지 못하면 형상/스텝 영역에 대한 미검증 또는 부적합으로 명시한다.
8. 단일 후보의 RMS가 작아졌다는 이유로 그 후보 방법을 선정하지 않는다. 소성값은 수집하거나 판정하지 않는다.
9. 변화량 장 오차는 `||(u_pred − u_ref) − (u_actual − u_ref)|| / ||u_actual − u_ref||`로 기록한다. 이는 기존 선정 기준과 함께 해석하는 추가 진단값이다. `reference_replay`와 `response_taylor`는 비교 대조군이다.

## 비드 5 민감도 확인

`python -m esl.benchmarks.shape_sensitivity --solver <solver> --out <dir> --jobs 4`로 실행한다.
차분 간격 ±0.05, ±0.025, ±0.0125 mm에 대해 수직 코너의 시간증분과 메시를 변경한다.
시간증분 실험은 `/DT/NODA` 계수 0.45, 0.225, 0.1125를 사용한다. 메시 실험은 960과 3,840쉘의 공통 절점을 비교한다.
접촉 개시는 강체 벽의 누적 법선 충격량이 처음 양수가 되는 구간으로 확인한다. 초기 간극만 0.02 mm 늘린 경우에는 공칭 착지 속도를 보존하도록 초기 속도를 조정한다.
응답 비교는 공칭 착지 시각 이후의 동일한 물리 시각에 정렬한다. 전체 39 ms와 초기 4 ms 등을 별도 기록한다.

`python -m esl.benchmarks.first_order_esl_example`은 F-ESL 논문 §5.1의 두 고정된 형상 점에서 직접 미분과 하중의 1차 보정을 확인한다. 출력에는 논문에 보고된 목적값과 이번 구현값을 함께 기록한다.
