# 코너 낙하에서 비드 설계를 평가하는 정적 대체방법 비교

상태: 실험 명세 v1.2, 2026-11-17. 기준 커밋 `685df7de4ce3970f301d9f9d0ba28bf6b49b6633`.
사용자 요청: 방법을 먼저 정의하고, 실제 충돌 동해석 결과로부터 후보 방법을 구현해
넓은 판재의 비드 최적화를 비교한다. 로컬 Codex에서도 같은 작업을 재현할 수 있어야 한다.

## 1. 질문과 범위

질문은 '기준 설계에서 만든 대체모델이 비드 변경의 실제 낙하 성능을 예측하고 개선안을
찾는가'이다. 기준 변위 재현이나 선형 왕복 성공만으로 이를 통과시켜서는 안 된다.
실제 비선형 동해석을 기준값으로 사용한다. 성공하지 못한 방법도 결과에서 제외하지 않는다.

실험 CLI와 별도 방법 비교 화면을 추가한다. 기존 등록 ESL, DOE 실행 경로·기본 설정과 순위 정의는 바꾸지 않는다.
`esl.mech.shell.ShellModel`, `esl.mech.kabsch`, 기존 3-2-1 지지 계산을 재사용한다.
공용 수치 계산은 IO와 `esl.doe`에 의존하지 않는 모듈에 둔다. 방법 차이는 선언형 표로 둔다.
물리·탐색 입력값은 `config/corner_drop_benchmark.json` 한 파일에서 읽는다. 플랫폼의 실험 실행
설정(enabled, solver_root 등)은 공용 DEFAULTS·backend 스키마·설정 YAML 2개에 같은 이름으로 둔다.

이것은 TV 조립체 복제가 아니라 독립 판재의 공개 재현 벤치마크다. 포장재, 나사, 질량 부품,
시험 상관성은 포함하지 않는다. 결과를 실제 TV 설계 검증으로 확대해서 표현하지 않는다.

  `6cb419677ca36d73acb96218cc0cf5e4f7d50494d9c7812ba27935e3c0f8ec94`.
- 일관 단위: mm, s, tonne, N, MPa. 가속도 mm/s², 밀도 tonne/mm³.
- 판: 800 × 450 × 0.8 mm. 명목 메시 40 × 24 QUAD, 최종 재검증 80 × 48.
- 재료: E=210000 MPa, ν=0.3, ρ=7.85e-9 tonne/mm³.
  탄소성 LAW2, a=250 MPa, b=1000 MPa, n=1, 변형률속도/열 연화/파손 없음.

- 0.2 ms 간격으로 좌표, 속도, 가속도, 접촉/벽력, 내부력, 질량, 소성변형률 및 응력 저장.
  솔버가 제공하지 않은 필드는 만들어 채우지 말고 해당 방법을 실패/불가로 기록한다.

## 3. 비드 설계변수와 공통 비교 조건

동일한 노드 ID와 연결을 유지한다. 전체 판의 초기 중립면에 6개 C1 연속 높이장을 두며,
깊이만 0~8 mm에서 바꾼다. x방향 2줄, y방향 2줄, 대각선 2줄이다.
기준 깊이는 각 2 mm, 개구 폭은 80 mm다. 판 가장자리에서는 높이를 0으로 부드럽게 줄인다.
이는 실제 프레스 공정 해석이나 제조 가능성 보증이 아닌 파라미터화된 비드 모핑이다.

두께와 재료는 고정한다. 모핑으로 늘어난 면적과 실제 질량을 계산하며, 기준 대비 질량
증가 2%를 넘는 설계는 배제한다. 법선 각도와 요소 면적/종횡비를 검사한다.
후보별 동일 질량이라고 임의로 주장하거나 두께를 몰래 조정하지 않는다.

## 4. 공통 표기와 평형

X(p): 설계 p의 충돌 전 좌표(판 고유 좌표계).
y0(t): 기준 동해석 좌표에서 전체 강체운동을 Kabsch로 제거한 좌표.
u0(t)=y0(t)-X(p0), Δu0_i=u0(t[i+1])-u0(t[i]).
K(p): 저장소의 선형 쉘 강성. 회전 자유도를 응축한 병진 강성은 Khat(p).
m(p): 실제 요소 면적·두께·밀도로 분배한 절점 질량.

선형 정적 변위에서는 미소 강체 성분 a+ω×r을 제거한다. 동해석의 유한 회전을
미소 회전 제거만으로 처리하지 않는다. 모든 누적/벡터 변환은 같은 판 좌표계에서 수행한다.

정적 3-2-1 지지는 강체 영공간 제거용 수치 게이지다. 물리적인 나사 고정으로 해석하지 않는다.
후보마다 힘 합, 모멘트 합, 각 지지 반력, 지지 반력의 모멘트, 해의 잔차를 별도 저장한다.
`norm(sum(R)) == 0`을 개별 반력이 없다는 뜻으로 사용하지 않는다.

관성완화 연산 IR(X,f,m): 질량중심 기준으로 병진 및 회전 가속도(6개)를 구해,
f에서 m*(a+α×r)을 빼서 합력·합모멘트를 제거한다. 이 연산은 강성이 낮은 탄성모드를
제거하는 필터가 아니다. 보정 전후 힘과 보정량을 모두 기록한다.

## 5. 비교할 방법 — 정의를 바꾸면 명세 버전도 올린다

| ID | 하중/강성 및 평가 정의 | 역할 |
|---|---|---|
| D0 displacement | 기준에서 f_i=Khat(p0)*u0(t_i). 모든 p에서 같은 f_i로 K(p)를 풀음. 후보 좌표에서 모멘트 보정 없음 | 현재 고정 ESL 방식 대조군 |
| D1 balanced_displacement | D0의 f_i에 후보 좌표 X(p), 절점 질량 m(p)의 IR를 적용한 뒤 정적 재풀이 | 전체 평형 변화만으로 설명되는 부분 진단 |
| P0 physical_acceleration | 기준 동해석에서 f_i=contact_i + m(p)*g - m(p)*a0_i. 세계 좌표에서 계산한 뒤 그 시점 Kabsch 회전으로 판 좌표계에 변환. 후보별 IR 후 정적 풀이 | 변형 가속도까지 포함하는 힘 기반 대체모델 |
| P1 contact_inertia_relief | 기준에서 측정한 접촉력(및 중력)을 판 좌표계로 변환하고 후보별 IR 후 정적 풀이. 실제 절점 변형 가속도는 쓰지 않음 | NOCS 접촉력 접근을 자유 판재에 적용한 **연구용 변형**, 논문 그대로 재현 아님 |
| I0 incremental_geometry | 기준 시간 경로의 y0(t_i)에서 Khat_i*Δu0_i로 증분 하중 생성. 후보 기준 형상은 y0(t_i)+normal0(t_i)*(h(p)-h(p0)). 각 모델에 기준 증분 하중을 적용, 증분 해를 누적 | DiESL을 비드 높이장에 확장한 **실험적 경로 매핑** |
| R0 ritz_reference | 각 기준 u0의 회전을 복원, 후보에서 같은 병진장에 대한 응축 에너지비 ρ를 구하고 예측장 u0/ρ로 평가. 힘 재풀이 결과도 따로 저장 | 기존 1-벡터 근사의 음성 대조군; 검증 없이 권장하지 않음 |

P0의 a0는 강체 가속도를 먼저 제거한 값이 아니라 세계 좌표의 전체 가속도다.
중복 관성 제거와 부호 오류를 방지한다. 그 후의 IR은 후보의 자유 강체 평형만 보정한다.
접촉력은 벽 반력의 부호와 판에 작용하는 힘을 구분하고, 선운동량 수지로 독립 확인한다.
체적 가속도 중력은 단위 변환을 명시한다. 회전 관성의 절점 모멘트를 무시한 얇은 쉘
병진 하중 근사라는 한계와, 원래 좌표/힘의 모멘트 수지를 함께 기록한다.

I0의 기준 형상과 예측 형상은 다르다. 예측 형상은 X(p)+누적 증분 해이며, 다음 모델의
강성을 이 예측 형상으로 자동 갱신하지 않는다. 비드는 강체로 고정하지 않는다.
normal0는 기준 변형 형상의 절점 평균 법선이다. 법선 오프셋 매핑은 새 비드의 실제
찌그러짐을 알고 있다는 뜻이 아니다. I0가 이를 해결했다고 미리 판정하지 않는다.

본 실험에서 목적함수는 모두 공통으로 '강체 제거 변위 RMS의 시간/하중 케이스 최대값'이다.
컴플라이언스와 최대 절점변위는 보조값이다. D0에서 저장소 기존 컴플라이언스 순위도
대조값으로 함께 기록해 목적함수 변경의 영향을 분리한다.

## 6. 탐색 및 실제 재낙하 판정

1. 실제 기준 낙하를 먼저 완료하고 원자료·품질 기록을 보존한다.
2. 기준 결과만으로 하중 시점과 I0 증분 시점을 고른다. 후보 재낙하 결과로 시점을 튜닝하지 않는다.
3. 고정 seed Sobol 후보 64개와 기준/축방향 미소 변경안을 동일하게 평가한다.
   각 방법의 최선점 주변에서 고정 예산의 좌표 탐색을 수행한다. 전역 최적이라고 부르지 않는다.
4. 각 방법의 최선안, ±1 mm 국부 변경안, 독립 Sobol holdout 8개를 실제로 다시 낙하시킨다.
   방법별 최선안이 같으면 중복 실행하지 않는다. 실패 설계도 기록에 남긴다.
5. 주 평가값: 각 설계 자체의 초기 형상을 기준으로 Kabsch 제거한 변위 RMS의 전체 시간 최대.
   보조값: 최대 순수 변형, 소성변형률의 최댓값/95백분위, 잔류변형, 접촉력, 에너지, 질량.
6. 순위 일치(Spearman), 개선/악화 방향 일치, 국부 민감도 부호, 최선안의 실제 개선율,
   솔버/대체모델 계산시간을 비교한다. 실패한 방법에 맞춰 평가 지표를 바꾸지 않는다.
7. 기준과 방법별 최선안에 대해 다른 자세/속도 조건을 추가 검증한다. 최소 하나의 실제
   개선안과 기준은 메시를 2배 세분화해 재검증한다. 이를 안 했으면 수행하지 않았다고 적는다.
8. 목표함수 5% 이상 개선되고 소성변형률 95백분위가 5%보다 더 악화되지 않으며 질량 제한을
   지킨 안을 '이 벤치마크에서 유효한 개선안'으로 판정한다. 모든 방법의 성공을 요구하지 않는다.
   한 번의 외부 반복 결과를 최적화 수렴이라고 부르지 않는다.

## 7. 품질 및 산출물

- 실제 solver 버전/해시, 입력 rad, starter/engine 로그, return code와 종료시간.
- 비정상 종료/음의 체적·과도한 관통·요소 삭제·질량 증가를 자동 감지한다.
- 선운동량 적분 수지, 에너지 수지, hourglass 에너지, contact work 확인.
  품질이 불충분하면 탐색을 진행하지 말고 모델을 수정하고 변경 이유를 기록한다.
- 원자료 NPZ: 초기/시간별 좌표, 시간, 질량, 힘, 가속도, 속도, 요소 소성변형률,
  필드명-단위-부호 매핑. 누락 데이터를 임의 생성하지 않는다.
- 설정/방법 버전/소스 SHA/seed/설계변수/결과를 JSON·CSV로 저장한다.
- 한국어 보고서: 실제 값과 대체모델 값을 구분한 비교표, 초기/최종 형상 이미지,
  기준·최선안 낙하 영상, 실패/미수행 항목, 로컬 재실행 명령.
- GUI 화면에서 수행한 것처럼 꾸미지 않는다. 실제 솔버와 저장소 코어를 쓰는 CLI 실행 결과와, 별도 실제 GUI 검증 여부를 구분한다.

## 9. 추가 실행 화면과 전달 조건 (사용자 추가 지시)

- 기존 비드 최적화/강성 평가 화면을 교체하지 않고 '코너 낙하 방법 비교' 진입 버튼과 별도 화면을 추가한다.
- 각 방법 이름, 대조군/실험적 확장 여부, 실행 버튼을 제공한다. 실제 CLI 계산을 호출한다.
- 방법별 실행과 전체 비교를 구분하고, 입력 준비/동해석/정적 탐색/재낙하 단계 및 실패 이유를 표시한다.
- 결과 표와 보고서/입력/로그 받기를 제공한다. 미실행 결과를 데모 수치로 채우지 않는다.
- 서버 설정으로 지정한 솔버와 명세의 고정 프리셋만 실행한다. 사용자가 임의 명령이나 경로를 실행할 수 없게 한다.
- 조회/실행 권한, 프로젝트 격리, 동시 실행 제한, 중복 실행 방지와 프로세스 종료 상태를 처리한다.
- 완료한 소스·방법 정의·재현 지시문·결과 요약은 원격 저장소의 별도 브랜치에 푸시한다.
  사용자 지시대로 PR은 만들지 않는다.

## 10. 기준 모델 확인 후 확정한 구현 세부 (v1.2, 후보 탐색 전)

- RWALL은 절점을 구속하므로 접촉 평면에 반두께(0.4 mm)를 더해 물리 바닥 z=0을 표현한다.
  침투량은 이 절점 접촉 평면을 기준으로 검사한다.
- `/ANIM/VECT/FREAC`의 `Reaction_Forces`가 판에 작용하는 RWALL 절점력이다.
  `Contact_Forces`는 인터페이스 접촉력이며 이 모델에서는 0이다.
  `FOPT`는 가상 벽 표시 절점에 있어 판 절점 하중으로 사용하지 않는다.
- `/TH/RWALL`의 FN/FT 시계열은 힘이 아닌 벽에 가해진 충격량이다. 부호를 반전하고
  판 선운동량 변화와 중력 충격량을 대조한다. 전체 가속도와 내부력도 별도로 평형 확인한다.
- 소성변형률은 `/ANIM/SHELL/EPSP/ALL`의 두께 방향 5개 적분점 중 요소별 최댓값이다.
  중앙 적분점만 출력하는 `/ANIM/ELEM/EPSP`를 굽힘 손상 지표로 쓰지 않는다.
- 기준 모델의 에너지 손실은 기본 시간간격에서 약 8%, 시간간격을 절반으로 줄여도 약 8%였다.
  따라서 이를 시간 적분 오차만으로 설명하지 않는다. 운동학적 벽 충격과 공간 이산화의
  영향을 포함한 한계로 기록한다. `/DT/NODA` scale=0.45, 최소값 0으로 질량 추가 없이 계산한다.
  **후보 결과를 보기 전** 거친 메시 탐색의 에너지 품질 기준을 10%로 확정했다.
  최종 세분화 메시에서는 5%를 별도 적용한다. 세분화/자세 변화가 불리하면 유효성을
  입증했다고 선언하지 않는다. 판정 기준의 이 변경 이력을 결과 보고서에도 표시한다.
- I0는 각 증분 해의 6개 강체 게이지만 기준 증분과 맞춘 뒤 누적한다. 기준 증분의
  탄성 성분을 후보 해에 주입하지 않는다. 같은 형상의 왕복에서 이 게이지 처리도 검사한다.
- 정적 공통 시점은 전체 시간에 등간격 5개, 그 중 RMS 최대 시점에 가장 가까운 한 시점을
  기준 RMS 최대 시점으로 교체한다. I0는 12개 구간에서 내부 시점 하나를 같은 최대 시점으로
  교체한다. 후보 동해석 결과를 이용해 시점을 조정하지 않는다.
- 중간 로컬 커밋은 생성했다. 현재 연결된 GitHub 계정은 대상 저장소의 `push:false`로
  원격 브랜치 작성이 거부됐다. 권한을 확보하지 않은 원격 저장을 완료했다고 표시하지 않는다.
